# Priyanka & Ajinkya Wedding Website

A responsive wedding website made with plain HTML, CSS and JavaScript.

## Files
- `index.html`: page content and structure
- `style.css`: design, colours, layout and mobile styling
- `script.js`: countdown, mobile menu, venue map link and RSVP email draft

## Preview and learn
1. Extract the ZIP.
2. Open `index.html` in your browser.
3. Open the folder in Visual Studio Code (or another text editor) to learn and edit the code.
4. Change the names/headings in HTML, then refresh the browser. Change colours in `style.css` under `:root`. Countdown and RSVP settings are in `script.js`.

## Personalise before publishing
- Replace the sample story with your own, if you want.
- Replace all "to be announced" event/venue details with confirmed information.
- Set `RSVP_EMAIL` in `script.js` to the email address where you want RSVP messages.
- Set `MAPS_URL` to your venue's Google Maps link.
- The RSVP form opens a pre-filled email draft; it does not save responses to a database or send automatically.
- Test the site on a phone and ask a friend to test the links before sharing.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com/
2. Create a **public** repository, for example `priyanka-ajinkya-wedding`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository's root.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then save.
7. After publishing, the URL usually looks like `https://YOUR-USERNAME.github.io/priyanka-ajinkya-wedding/`.
8. Open that URL on your phone and test it. Official guide: https://docs.github.com/en/pages/quickstart

## Public website privacy
Anyone with the public URL may view it, and a public repository makes its source code visible. Do not post private phone numbers, home addresses, or sensitive family information. Only use photos you have permission to share.
